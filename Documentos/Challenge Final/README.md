# Entrega do Challenge — Automação de Testes (Robot) — Cinema

Repositórios da aplicação sob teste:
- Back-end: https://github.com/juniorschmitz/cinema-challenge-back
- Front-end: https://github.com/juniorschmitz/cinema-challenge-front

## O que está neste repositório

- `docs/` — Documentos:
  - `PLANO-DE-TESTES.md` — Plano de testes funcional (baseado no mapa mental)
  - `ESTRATEGIA.md` — Padrões/organização sem alterar sua suíte
  - `EXECUCAO.md` — Como subir back/front
  - `SCRIPTS-SETUP.md` — Consolidação dos scripts de setup e troubleshooting
  - `BUG-TEST-CASES.md` - Todos os relatados nos testes da api
  - `mapa-mental.png` — Mapa mental de todas as endpoints da API
- `tests/` — Testes feitos usando **robot-framework**:
  - `Backend tests` - Testes que cobrem todos os endpoints da API
  - `Frontend tests` - Alguns testes aplicados na versão Web

## Como integrar ao seu repositório
1. Copie a pasta `docs/` para a raiz do seu repositório de automação (não substitui seus testes).
2. Caso deseje, mova `tests/` para onde estão seus testes atuais (se for o mesmo conteúdo, ignore).
3. Suba commits frequentes, crie branches por assunto e referencie as issues.
