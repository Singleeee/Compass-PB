# HISTÓRIAS DE USUÁRIO (Trechos Relevantes)

## Perfis
- **Visitante**, **Usuário** (autenticado), **Administrador**.

## Autenticação
- **Registrar conta**: validar e-mail/senha, impedir duplicidade, direcionar ao login.
- **Login**: autenticar, manter sessão (JWT), redirecionar home.
- **Perfil**: visualizar/atualizar dados com confirmação.

## Filmes
- **Listar filmes** (grid responsivo com pôster, título, classificação).
- **Detalhes do filme** (sinopse, elenco, duração) e **horários** disponíveis.

## Sessões
- **Ver horários por filme** (data, hora, sala, disponibilidade).

## Reservas
- **Selecionar assentos** (múltiplos, bloquear ocupados, subtotal dinâmico).
- **Checkout** (resumo, total, método de pagamento simulado, confirmação).
- **Minhas Reservas** (cards com filme/data/assentos/status).

> Estes itens foram base para os cenários automatizados da suíte existente.
